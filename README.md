# roomlab

A data-driven 3D interior design application built with React, TypeScript, and Vite.

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in your terminal to view the application.

## Dataset

The IKEA furniture dataset is stored in `public/ikea.csv`.

## Tech Stack

- React
- TypeScript
- Vite
